# 🐾 Paw Art Studio

Сайт студии дизайна: регистрация, баланс, заказы, портфолио, мессенджер, админка с защитой главного админа.

## Стек

- Node.js 18+ (Express + Socket.IO)
- SQLite (better-sqlite3)
- JWT + bcrypt
- Ванильный HTML/CSS/JS

## Защита главного админа

Главный админ из `.env` помечается флагом `is_root = 1` в БД:
- **Никто** (включая других админов) не может снять его с роли через сайт
- Только он может назначать новых админов
- Только он может менять баланс других админов
- При перезапуске сервера его роль восстанавливается из `.env` автоматически
