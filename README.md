# Paw Art Studio

Сайт студии дизайна с регистрацией, подтверждением email, кошельком, промокодами, реферальной системой и админ-панелью.

## Стек

- **Backend:** Node.js 18+, Express, Socket.IO
- **БД:** SQLite (better-sqlite3)
- **Auth:** JWT + bcrypt
- **Почта:** Nodemailer (Gmail SMTP)
- **Платежи:** ЮKassa
- **Frontend:** ванильный HTML/CSS/JS

## Быстрый старт

```bash
# 1. Установить зависимости
npm install

# 2. Создать .env из примера
cp .env.example .env

# 3. Заполнить .env (см. ниже)

# 4. Запустить
npm start


## Партнёрская программа

### Настройка
- Добавьте партнёра в админ-панели → «Партнёры».
- Чтобы открыть партнёру личный кабинет, укажите email его зарегистрированного аккаунта с подтверждённой почтой. Для уже созданного партнёра аккаунт можно привязать кнопкой «Привязать аккаунт».
- Скопируйте ссылку вида `https://pawartstudio.store/?ref=CODE` и передайте её владельцу сообщества.
- Партнёр входит в свой аккаунт на сайте и открывает `/partner.html`.
- В кабинете партнёр видит активные промокоды, копирует их, отслеживает статистику и подаёт заявки на выплату.

### Атрибуция и скидки
- Срок атрибуции задаётся переменной `PARTNER_ATTRIBUTION_DAYS` (1–365 дней, по умолчанию 30).
- Переход учитывается не чаще одного раза за 24 часа с одного хешированного IP для конкретного партнёра.
- Подписанный сервером токен связывает регистрацию с партнёром; повторная загрузка сайта не продлевает срок атрибуции.
- Партнёрский промокод применяется к бюджету при создании заказа: итоговая сумма сохраняется в проекте, исходная сумма и размер скидки остаются в истории.
- Отправка контактной заявки с промокодом не расходует его. Использование фиксируется при создании реального проекта.

### Начисления и выплаты
- Начисление создаётся после завершения проекта. Одобрить его можно только после подтверждения оплаты.
- Оплатить заказ можно через ЮKassa из карточки проекта, если магазин настроен; также администратор может вручную подтвердить внешний перевод.
- Для автоматической оплаты заказа нужны `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` и `SITE_URL`; в кабинете ЮKassa настройте webhook на `https://pawartstudio.store/api/payments/webhook` для событий `payment.succeeded` и `payment.canceled`.
- Партнёр отправляет заявку на выплату из `/partner.html`. Заявка резервирует доступный остаток, чтобы нельзя было запросить одну сумму несколько раз.
- Администратор одобряет заявку, выполняет перевод вручную и только после фактического перевода отмечает её выплаченной.
- При отмене оплаченного заказа начисление сторнируется. Если партнёру уже перечислили вознаграждение, сумма возврата учитывается как отрицательная корректировка будущего баланса.
- Возврат клиенту нужно фактически выполнить в ЮKassa/банке отдельно; после этого администратор фиксирует номер операции в карточке заказа или партнёрском журнале. Сервер не инициирует возврат денег автоматически.

### Конкурсы и реклама
- Администратор создаёт конкурсы и рекламные размещения из панели партнёров.
- Публикация и скрытие выполняются кнопками в том же разделе; на публичной странице показываются только активные размещения и конкурсы.

Партнёрская витрина художников в эту программу не входит.
